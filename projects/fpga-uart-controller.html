01 / Silicon Serial Communication Fundamentals

While microcontrollers hide serial communication behind fixed hardware registers, implementing a UART on an FPGA requires building the underlying shift registers, bit-period timers, and asynchronous edge detectors directly in synthesizable RTL.

The core converts parallel 8-bit bus bytes into a deterministic serial bitstream over a single physical trace and reconstructs incoming asynchronous serial streams without data loss.

02 / Receiver 16x Oversampling Architecture

Because the incoming serial stream is completely asynchronous to the local FPGA clock oscillator, the receiver cannot simply sample the input line at nominal bit intervals. The core implements a 16x oversampling state machine:

Clock (e.g. 50 MHz) ──► [Baud Rate Clock Divider] ──► 16x Baud Ticks │ +─────────────────────────────────────────────────────────+ │ ▼ [RX Pin] ──► [2-Stage Flip-Flop Synchronizer] ──► [Falling Edge Start-Bit Detector] │ ▼ +───────────────────────────────+ | RX State Machine: | | • Count 8 ticks to center | | • Sample bits at ticks 7,8,9 | | • 3-sample majority voting | | • Shift into 8-bit register | | • Verify stop bit asserted | | • Raise o_rx_dv valid flag | +───────────────────────────────+

03 / Parameterized Clock Divider Timing

The timing of the entire core is parameterized via a single VHDL generic:

g_CLKS_PER_BIT = (System Clock Frequency) / (Target Baud Rate)
System Clock Baud Rate Calculated `g_CLKS_PER_BIT` Baud Error Rate
50.000 MHz 9,600 baud 5,208 clock cycles < 0.01% (Exact match)
50.000 MHz 115,200 baud 434 clock cycles < 0.08% (Well within ±2% UART tolerance)
100.000 MHz 115,200 baud 868 clock cycles < 0.04%

04 / Synthesizable VHDL Core Implementation

entity uart_tx is generic ( g_CLKS_PER_BIT : integer := 868 -- 100 MHz clock / 115200 baud ); port ( i_clk : in std_logic; i_tx_dv : in std_logic; i_tx_byte : in std_logic_vector(7 downto 0); o_tx_active : out std_logic; o_tx_serial : out std_logic; o_tx_done : out std_logic ); end uart_tx;

Self-Contained Verification: `UART_TB.vhd` & GHDL

The repository includes an automated loopback testbench connecting the transmitter serial output directly to the receiver input. It sequentially transmits test patterns 0xA5 (10100101) and 0x3C (00111100), asserting frame completion flags and verifying identical byte reconstruction. Packaged with a one-click simulation script run_sim.sh for GHDL and GTKWave.

05 / Hardware Roadmap & Scope

  • Hardware Parity Generation: Adding configurable even/odd parity bit insertion and parity error flags.
  • Synchronous Dual-Clock FIFO Buffers: Decoupling the peripheral bus clock domain from serial burst arrival.
  • Baud Auto-Detection: Measuring the pulse width of standard ASCII carriage returns to calibrate g_CLKS_PER_BIT dynamically.
