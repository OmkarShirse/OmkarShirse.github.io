01 / The Real-World Engineering Problem

Avian embryonic development is exceptionally intolerant of environmental fluctuation. A prolonged temperature drop below 35°C arrests cellular division, while overheating above 39°C causes fatal protein denaturation within hours.

Equally critical is the two-stage relative humidity requirement:

  • Stage 1 (Days 1 to 18): Moderate relative humidity (55%–60% RH) allows moisture to evaporate from the egg at a controlled rate, expanding the internal air cell so the embryo can take its first breath before pipping.
  • Stage 2 (Days 19 to 21 — Hatching Phase): Humidity must be elevated to 65%–75% RH to soften the calcium shell and prevent the inner shell membrane from drying out and shrink-wrapping the chick.

Conventional small-scale incubators rely on analog bi-metallic thermostats and manual water trays, causing erratic thermal oscillation and high hatch failure rates. This project engineers a self-governing closed-loop IoT system delivering precision environmental control.

02 / System Architecture & Signal Flow

The system is architected around an ESP8266 NodeMCU-12E running real-time sensor polling, day-tracking counters, and hysteresis-based relay drivers with galvanic isolation:

04 / Firmware Implementation & Failsafes

To prevent rapid relay cycling (chatter) that degrades mechanical contacts and introduces thermal overshoot, the firmware implements a ±0.3°C hysteresis band. The incubation stage is evaluated every cycle against the active calendar day:

#include <DHT.h> #include <BlynkSimpleEsp8266.h> #include "stages.h" void regulateMicroclimate(float currentTemp, float currentHumidity, int currentDay) { // Dynamic stage evaluation based on elapsed incubation days float targetTemp = (currentDay <= 18) ? 37.5 : 37.2; float targetHumidity = (currentDay <= 18) ? 58.0 : 70.0; // Hysteresis Thermal Loop (Active-LOW Relay) if (currentTemp < (targetTemp - 0.3)) { digitalWrite(PIN_RELAY_HEATER, LOW); // Heater ON } else if (currentTemp >= targetTemp) { digitalWrite(PIN_RELAY_HEATER, HIGH); // Heater OFF } // Humidity Modulation with 2.5% Deadband if (currentHumidity < (targetHumidity - 2.5)) { digitalWrite(PIN_RELAY_MIST, LOW); // Ultrasonic Mist ON } else if (currentHumidity >= targetHumidity) { digitalWrite(PIN_RELAY_MIST, HIGH); // Mist OFF } }

Network Decoupling & Local Failsafe Autonomy

Standard connected microcontroller sketches block execution when waiting for Wi-Fi reconnection handshakes. In this firmware, the control loop is separated from network synchronization using non-blocking software timers. If Wi-Fi drops out, the incubator maintains microclimate regulation autonomously indefinitely.

Engineering Roadmap / Future Improvements:

  • Egg Turner Stepper Integration: Automated 45° tilting every 4 hours to prevent embryonic adhesion to the outer shell membrane.
  • PID Thermal Tuning: Upgrading from hysteresis relays to SSR (Solid State Relay) PWM drive for true ±0.05°C ripple stability.
  • Multi-Species Microclimate Profiles: Firmware support for Quail (17 days @ 37.7°C), Duck (28 days @ 37.5°C), and Turkey (28 days).
