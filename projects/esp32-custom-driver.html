01 / Motivation: Bypassing Vendor Hal Bloat

Standard vendor SDKs prioritize generality and safety at the expense of deterministic execution time. In ESP-IDF, every single call to gpio_set_level() executes a spinlock critical section (portENTER_CRITICAL), executes range boundary branch logic, and suffers unpredictable flash-cache stalls.

For bit-banging communication protocols (DShot, WS2812, fast parallel displays) and high-rate sensor polling, spinlock overhead limits performance to ~1.8 MHz. This stack was engineered in pure C99 to provide a zero-lock, register-level architecture with modular ESP-IDF v5 components.

03 / Component Breakdown & Silicon Implementation

1. Fast GPIO Register Driver (`components/gpio_fast`)

Replaces slow SDK calls with direct writes to the memory-mapped GPIO controller:

  • GPIO_OUT_W1TS_REG (0x3FF44008): Write-1-To-Set asserts pins HIGH atomically without reading prior state.
  • GPIO_OUT_W1TC_REG (0x3FF4400C): Write-1-To-Clear asserts pins LOW atomically.
  • IRAM Resident: Marked IRAM_ATTR and always_inline to guarantee execution during flash cache write-erase windows.
// gpio.h — Hot-path IRAM inlined register control static inline void IRAM_ATTR gpio_fast_set(uint8_t pin) { if (pin < 32) { REG_WRITE(GPIO_OUT_W1TS_REG, (1UL << pin)); } else { REG_WRITE(GPIO_OUT1_W1TS_REG, (1UL << (pin - 32))); } } static inline void IRAM_ATTR gpio_fast_clear(uint8_t pin) { if (pin < 32) { REG_WRITE(GPIO_OUT_W1TC_REG, (1UL << pin)); } else { REG_WRITE(GPIO_OUT1_W1TC_REG, (1UL << (pin - 32))); } }

2. MPU-6050 14-Byte Atomic Burst Read

Sequential I2C reads of separate sensor axes introduce temporal skew. This driver executes a single continuous 14-byte burst read starting at ACCEL_XOUT_H (0x3B): [Accel X, Y, Z] → [Temp] → [Gyro X, Y, Z]. All axes are captured within the same internal ADC sample window.

3. DSP & Attitude Estimation

The firmware deploys an $O(1)$ ring-buffer Moving Average filter to cancel high-frequency vibration, and combines it with a 6-DOF Madgwick Quaternion filter with fast inverse square root optimization to eliminate low-frequency gyroscope drift.
