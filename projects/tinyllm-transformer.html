01 / The Engineering Challenge: LLMs on 520 KB RAM

Modern Large Language Models require hundreds of gigabytes of high-bandwidth VRAM and multi-gigahertz tensor accelerators. Bringing autoregressive transformer inference to a first-generation ESP32 (240 MHz, 520 KB internal SRAM, 4 MB SPI Flash) requires breaking through fundamental memory constraints.

Standard PyTorch runtimes cannot execute on microcontrollers due to dynamic memory allocation fragmentation, heavy floating-point dependencies, and bloated activation buffers. TinyLLM solves this by combining custom symmetric 8-bit quantization (Q8), Flash-mapped static weights, and a zero-heap static memory layout.

02 / Silicon Memory Budget Breakdown

To guarantee uninterrupted execution without stack overflow or heap crashes, every buffer is allocated at compile-time:

Memory Section Size Used Hardware Location Optimization Strategy
Model Parameters (~77 K) ~74 KB – 180 KB SPI Flash Memory (RODATA) Mapped directly via memory-mapped Flash; 0 bytes SRAM consumed
Key-Value Cache (KV) ~64 KB Internal SRAM (DRAM) Static ring buffer sized strictly for 64-character context window
Activation & Logits Buffer ~4 KB Internal SRAM Single reusable working buffer for multi-head attention and FFN
Dynamic Allocations (`malloc`) 0 Bytes Heap Strict zero dynamic allocation during the inference loop

04 / C++ Inference & Temperature Sampler

The inference engine operates with fixed numerical stability. To sample tokens without floating-point overflow during exponential calculation, the logits undergo max-subtraction normalization:

// sampler.h — Temperature and Top-K categorical sampling int sample_next_token(float* logits, int vocab_size, float temperature, int top_k) { // 1. Apply temperature scaling for (int i = 0; i < vocab_size; i++) { logits[i] /= temperature; } // 2. Max subtraction for numerical stability float max_val = -1e9f; for (int i = 0; i < vocab_size; i++) { if (logits[i] > max_val) max_val = logits[i]; } // 3. Softmax probability distribution float sum_exp = 0.0f; for (int i = 0; i < vocab_size; i++) { logits[i] = expf(logits[i] - max_val); sum_exp += logits[i]; } // 4. Top-K cutoff & cumulative probability roll return top_k_categorical_sample(logits, sum_exp, top_k); }

Interactive Serial Command Protocol

The firmware features an on-chip command parser listening to the USB serial link at 115200 baud. Engineers can type prompts directly or configure runtime hyper-parameters live without re-flashing: temp:0.7 (adjusts entropy), topk:5 (controls sampling diversity), and ctx:reset (clears the KV-cache).
