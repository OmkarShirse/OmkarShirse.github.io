Smart Egg Incubation System

IoT incubation system maintaining temperature at 37°C and humidity at 85%, the exact conditions eggs need. ESP8266 with DHT22 reads sensors continuously. Fan, UV light, and mist humidifier activate automatically. Monitored live on any phone via Blynk. Published in IJRESM, co-authored with the team at MGM.

Custom Embedded Driver

Low-level peripheral drivers written from scratch in C and Rust for SPI, I2C, UART, and CAN. No HAL abstractions, no bloat. Tight, portable code debugged at signal level with JTAG and a logic analyzer. Rust used for memory-safe driver modules where correctness is critical.
